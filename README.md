## What This Is

Centralized configuration management — store, version, and distribute app configs with secrets encryption and Docker deployment.

Built for operators who want a self-hosted, Docker-deployed solution they control.

## Quick Start

### pip

```bash
pip install configvault
```

### Docker (recommended)

```bash
git clone https://github.com/OneByJorah/ConfigVault.git
cd ConfigVault
docker compose up -d
```

### From Source

```bash
git clone https://github.com/OneByJorah/ConfigVault.git
cd ConfigVault
pip install -r requirements.txt
python3 app.py
```

## Features

- **Self-hosted** — no cloud dependencies, run on your own hardware
- **Docker Compose** — full stack deployment with one command
- **pip package** — install via PyPI
- **Dark theme** — operational, clean UI

- **Centralized config storage** — single source of truth for all app configs
- **Versioning** — track config changes over time
- **Secrets encryption** — encrypt sensitive values at rest
- **Distribution** — push configs to apps and services
- **Docker Compose deployment** — full stack with one command
- **Dark theme** — operational, clean UI

## Tech Stack

- **Backend** — Python 3.11+, pydantic, pyyaml
- **Deployment** — Docker Compose, pip install
- **Configuration** — environment variables, config files
